AI Data Engineering Framework

Automacao de Pipelines ETL com Agentes Autonomos e Protocolo MCP

1. Introducao

Este projeto representa a convergencia entre a Engenharia de Dados Tradicional e a Inteligencia Artificial Generativa. O objetivo principal foi criar um sistema autonomo capaz de gerenciar a infraestrutura de dados (Apache NiFi), tomar decisoes de filtragem de dados e persistir informacoes em um banco de dados relacional (MySQL) sem intervencao manual continua.

3. Arquitetura MCP (Model Context Protocol)

Diferente de scripts comuns, este projeto implementou um Servidor MCP. Isso permite que qualquer modelo de linguagem utilize o Apache NiFi como uma extensao de suas capacidades nativas.

Ferramentas Expostas (Tools):

  • create_nifi_processor: Capacidade de expansao do Canvas.
  • list_canvas_state: Capacidade de leitura e consciencia situacional.
  • get_nifi_bulletins: Capacidade de diagnostico de erros.

4. Implementacao do Pipeline ETL

Fluxo de Dados:

  1. Extracao: Chamada via InvokeHTTP para APIs REST.
  2. Filtragem: Uso de QueryRecord com SQL gerado pela IA.
  3. Carga: Persistencia via PutDatabaseRecord no MySQL.
  4. Observabilidade: Log de erros automático sugerido pela IA.
# Exemplo de SQL gerado pela IA para filtragem
SELECT * FROM FLOWFILE
WHERE title LIKE '%technology%'
OR body LIKE '%software%'

5. Auditoria de IA e Self-Healing

O estagio final envolveu um Agente Auditor (CrewAI). O agente analisou os componentes ativos e identificou a ausencia de tratamento de excecoes. Como resultado, ele recomendou a criacao de um processador de logs de erro (LOG_ERRO_AUTOMATICO).

6. Guia Operacional (Manutencao)

Como Reiniciar o Ecossistema:

  1. Ligar MySQL.
  2. Ligar Ollama (ollama run llama3.2).
  3. Ligar Apache NiFi (run-nifi.bat).
  4. Ativar Ambiente Python (.\venv\Scripts\Activate.ps1).
  5. Rodar o Inspetor MCP para testes:
    npx @modelcontextprotocol/inspector python src/nifi_mcp_server.py
