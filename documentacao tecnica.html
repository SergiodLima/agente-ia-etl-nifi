Automação de Pipelines ETL com Agentes de IA Local (NiFi + Ollama)

1. Visão Geral da Arquitetura

Este sistema utiliza um modelo de linguagem (LLM) para traduzir requisitos de negócio em comandos técnicos via API REST, automatizando a orquestração no Apache NiFi.

2. Guia de Implementação (Passo a Passo)

Siga estas etapas para replicar o ambiente de automação autônoma.

1 Configuração do Ambiente de IA

O cérebro do sistema roda localmente para garantir privacidade e baixa latência.

  • Instale o Ollama (ollama.com).
  • Baixe o modelo necessário via terminal: 
    ollama pull llama3.2
  • Certifique-se de que o serviço está rodando em http://localhost:11434.

2 Preparação do Apache NiFi

O NiFi atuará como o motor de execução do ETL.

  • Inicie o NiFi (recomendado versão 1.15+ ou 2.x).
  • Acesse as Controller Settings e certifique-se de ter um usuário com permissões de leitura/escrita no canvas.
  • Caso use HTTPS com certificado autoassinado, prepare as credenciais (Login/Password ou Token).

3 Setup do Ambiente Python

Instale as dependências para conectar a IA ao NiFi:

pip install nipyapi langchain_openai urllib3
Nota: Usamos langchain_openai apontando para o endpoint local do Ollama para manter compatibilidade de API.

4 Implementação do Script de Automação

O script deve conter três componentes lógicos principais:

  1. Conexão: Configurar nipyapi.config.nifi_config.host.
  2. Prompt System: Instruir a IA a retornar apenas JSON com "nome_processador" e "url_api".
  3. Execução: Utilizar nipyapi.canvas.create_processor() para instanciar o componente no NiFi.

3. Lógica do Agente (Prompt Engineering)

Para o sucesso da replicação, o System Prompt deve ser rigoroso:

"Você é um engenheiro de dados sênior. 
Sua tarefa é receber um pedido de negócio e transformá-lo em parâmetros técnicos.
Retorne SEMPRE no formato JSON:
{
  'name': '[Nome Profissional]',
  'url': '[URL de API pública real correspondente]'
}"

4. Resultados e Validação

Após a execução do script, valide os seguintes pontos na interface do NiFi:

  • O processador InvokeHTTP foi criado no Root Process Group?
  • A propriedade Remote URL foi preenchida corretamente pela IA?
  • O nome do componente segue o padrão profissional sugerido?
