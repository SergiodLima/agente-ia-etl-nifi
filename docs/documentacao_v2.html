Guia Técnico de Replicação: ETL Autônomo com IA

Integração Apache NiFi + Ollama + Python + MySQL

1. Introdução

Este documento detalha o processo de criação de um agente de inteligência artificial capaz de projetar, configurar e executar pipelines de dados no Apache NiFi de forma autônoma, utilizando processamento de linguagem natural (LLM) local para tomada de decisão.

2. Pré-requisitos do Sistema

  • Sistema Operacional: Windows 10/11 (PowerShell recomendado).
  • Java: JDK 11 ou 17 (Necessário para o Apache NiFi).
  • Python: Versão 3.10 ou superior.
  • Banco de Dados: MySQL 8.0+.
  • Hardware: Mínimo 16GB RAM (recomendado para rodar NiFi + IA simultaneamente).

3. Preparação do Ambiente

3.1. Apache NiFi

1. Baixe o binário do NiFi em nifi.apache.org.
2. Extraia em C:\nifi.
3. Execute bin\run-nifi.bat.
4. No primeiro boot, abra logs\nifi-app.log e procure por Generated Username e Generated Password.

3.2. Ollama (Cérebro da IA)

1. Instale o Ollama em ollama.com.
2. No terminal, baixe o modelo leve: ollama run llama3.2.
3. Mantenha o Ollama rodando durante toda a execução do projeto.

3.3. Ambiente Python

Crie um ambiente virtual e instale as bibliotecas de integração: 
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install nipyapi langchain_openai urllib3

Execute o script abaixo para preparar a tabela de destino:

5. O Script de Automação (Coração do Projeto)

Este script Python utiliza o NiPyApi para comandos técnicos e LangChain para conectar ao Ollama. Salve como agente_nifi_mysql.py.

# -*- coding: utf-8 -*-
import nipyapi
from nipyapi import canvas, security
import urllib3
import re
from langchain_openai import ChatOpenAI

# Desativa avisos de seguranca
urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)

# CONFIGURACOES NIFI
NIFI_USER = 'SEU_USUARIO_AQUI'
NIFI_PASS = 'SUA_SENHA_AQUI'
nipyapi.config.nifi_config.host = 'https://localhost:8443/nifi-api'
nipyapi.config.nifi_config.verify_ssl = False
nipyapi.config.nifi_config.username = NIFI_USER
nipyapi.config.nifi_config.password = NIFI_PASS

def montar_pipeline(nome_projeto, sql_ia, url_api):
    security.service_login(username=NIFI_USER, password=NIFI_PASS)
    root_id = canvas.get_root_pg_id()
    root_pg = canvas.get_process_group(root_id, 'id')

    # 1. CRIAR EXTRATOR (InvokeHTTP)
    type_http = canvas.get_processor_type('InvokeHTTP')
    proc_http = canvas.create_processor(root_pg, type_http, (400, 100), f"API_{nome_projeto}")
    conf_http = proc_http.component.config
    conf_http.properties = {'Remote URL': url_api}
    conf_http.auto_terminated_relationships = ['Original', 'Failure', 'Retry', 'No Retry']
    canvas.update_processor(proc_http, conf_http)

    # 2. CRIAR FILTRO (QueryRecord)
    type_query = canvas.get_processor_type('QueryRecord')
    proc_query = canvas.create_processor(root_pg, type_query, (400, 350), "FILTRO_IA")
    conf_query = proc_query.component.config
    conf_query.properties = {'tech_posts': sql_ia}
    conf_query.auto_terminated_relationships = ['original', 'failure']
    canvas.update_processor(proc_query, conf_query)

    # 3. CRIAR CARREGADOR (PutDatabaseRecord)
    type_db = canvas.get_processor_type('PutDatabaseRecord')
    proc_db = canvas.create_processor(root_pg, type_db, (400, 600), "MYSQL_LOADER")
    conf_db = proc_db.component.config
    conf_db.properties = {'Statement Type': 'INSERT', 'Table Name': 'tb_posts_tecnologia', 'Database Dialect': 'MySQL'}
    conf_db.auto_terminated_relationships = ['success', 'failure', 'retry']
    canvas.update_processor(proc_db, conf_db)

    # 4. CONECTAR COMPONENTES
    canvas.create_connection(proc_http, proc_query, relationships=['Response'])
    proc_q_new = canvas.get_processor(proc_query.id, 'id')
    canvas.create_connection(proc_q_new, proc_db, relationships=['tech_posts'])
    return "Pipeline Criado com Sucesso!"

# IA PENSANDO
llm = ChatOpenAI(model='llama3.2', base_url="http://localhost:11434/v1", api_key="ollama")
prompt = "SQL SELECT FROM FLOWFILE WHERE title LIKE '%software%'. Only SQL."
sql_limpo = re.sub(r'```sql|```|`', '', llm.invoke(prompt).content.strip()).replace('\n', ' ')

print(montar_pipeline("PROJETO_IA", sql_limpo, "https://jsonplaceholder.typicode.com/posts"))

6. Configurações Manuais no NiFi

Importante: Os "Controller Services" devem ser ativados manualmente na interface para que o NiFi tenha acesso aos drivers JDBC do MySQL.
  • DBCPConnectionPool: Configure com o driver mysql-connector-java.jar e a URL jdbc:mysql://localhost:3306/db_automacao_ia.
  • JsonTreeReader: Para ler os dados JSON da API.
  • JsonRecordSetWriter: Para preparar o dado para o MySQL.

7. Troubleshooting (Resolução de Problemas)

  • Erro 401 Unauthorized: O usuário e senha do NiFi mudam se você apagar a pasta conf. Verifique sempre o log.
  • SyntaxError Unicode: Nunca use acentos nos comentários ou strings do Python se estiver usando o PowerShell sem configuração UTF-8.
  • Relationship Invalid: Se a "setinha" entre o Filtro e o Banco der erro, certifique-se de que o nome da propriedade no QueryRecord é idêntico ao nome da Relationship na conexão.
